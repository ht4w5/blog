# Blog

A personal blog published at the root of a GitHub Pages domain, together with a
directory of other pages published under the same domain.

## Language

**Site directory**:
A manually maintained listing of destinations published under this domain, presented as its own page.
_Avoid_: paths page, links page, sitemap

**Directory entry**:
One destination listed in the site directory.
_Avoid_: link item

**Button wall**:
The showcase of 88×31 buttons presented as a section of the homepage.
_Avoid_: badge collection, buttons page

**Button**:
A classic 88×31 pixel web button image linking to a destination.
_Avoid_: badge, chip

**Flair badge**:
An 88×31 pixel decorative image with no destination.
_Avoid_: static badge, non-link button

**Backref**:
The `↩` return link at a footnote definition pointing back to the reference that cited it.
_Avoid_: back-link, return link, footnote anchor

**Accent color**:
The single brand color used for links and interactive affordances.
_Avoid_: link color, brand color, theme color

**Site nav**:
The persistent top bar of every page, containing the site title, the bracket nav links, search, and the theme toggle.
_Avoid_: header, navbar, menu

**Table of contents**:
The generated outline of a post's h2 and h3 headings, shown as a sticky sidebar on wide screens and a collapsed disclosure above the post content on narrow screens.
_Avoid_: TOC widget, outline, sidebar
