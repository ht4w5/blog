# 03: Tags

**What to build:** Tag system — `/tags` page lists all tags with post counts, `/tags/[tag]` shows filtered posts for that tag. Tag pills on the homepage link to the filtered tag pages.

**Blocked by:** 01-project-skeleton

**Status:** ready-for-agent

- [ ] `/tags` page lists all tags with post counts
- [ ] Each tag on `/tags` links to `/tags/[tag]`
- [ ] `/tags/[tag]` shows all non-draft posts with that tag in reverse chronological order
- [ ] Tag list pages use the same list style as the homepage (date, title, tag pills)
- [ ] Tag list pages are paginated at 20 per page
- [ ] Invalid tag URL shows "No posts tagged '[tag]'" with link to `/tags`
